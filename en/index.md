Credibility tags are separate from categories: ⚠️ engagement bait (traffic funnels, referral codes, course funnels), concept animation / concept interface (a designed picture, not a real product or a measured result), AI-generated, post-production packaging, claim unverified, commercial with no repo, paid template, comedy sketch. GitHub preview images come from GitHub Open Graph cards.

Entries tagged engagement bait put ⚠️ beside the link and beside URLs in the description.
