### [Filee: a local tool that converts a file when you drag it](https://github.com/KnifeLemon/Filee)

Hold a key, drag a file, and pick the output format next to the cursor

KnifeLemon's free open-source converter: hold Ctrl (Option on macOS), drag a file, and a ring menu of only the formats that apply pops up by the cursor. Drop it and the file is converted next to the original. It covers images, PDF, Word, Excel, PowerPoint, HWP, audio and video, ebooks, and archives. It does not need Office or LibreOffice, and it stays offline and does not upload. Windows 10/11, Linux x64/ARM64; macOS is a preview. MIT. The README says 270 formats and the repo blurb says 263. Latest release v2.2.0 (2026-10-28); installer downloads over time are about 552,000. It is not an AI tool. The video (DevPik) is an AI voiceover plus a polished mockup of a scrolling README, with no live demo. Music: light royalty-free synth-pop. Interview takeaway: an interface that only shows the choices that are valid right now reduces mistakes by design.
