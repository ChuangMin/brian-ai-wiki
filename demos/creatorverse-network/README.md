# Creatorverse：發光的創作者節點網路

影片 44（Brody，FounderOS／Content Lab，https://www.facebook.com/reel/1423421943269401）裡 Creatorverse 分頁的互動重製。單一 `index.html`，純 Canvas，不需外部資源。

- 44 個節點：你的帳號 4、追蹤中 25、觀察名單 12、系統建議 3（數量照影片上方的篩選列）。節點會脈動，背景有三圈緩慢轉動的軌道環。
- 拖曳平移、滾輪縮放；滑過節點只亮出它和鄰居的連線；點節點開側欄看假數據（追蹤者、爆紅倍數、單次抓取估價等）；上方標籤可篩選群組；「重設視角」回到初始畫面；「回 wiki 首頁」連到 `../../`。
- 網址加 `?auto` 會自動選取一個節點並打開側欄（截圖用）。
- ⚠️ 所有帳號名稱與數字都是用固定種子隨機產生的假資料，與任何真實創作者無關；沒有爬取，也不連 Apify 或任何外部服務。
