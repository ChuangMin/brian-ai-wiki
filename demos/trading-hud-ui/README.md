# Trading HUD UI（SEQ 0049／影片 94）

依 Tommy Vaga ALGORY 新片裡的直式（9:16）科幻交易儀表板逐畫面重製，在瀏覽器以單一 canvas 畫出九種可切換的虛構 HUD。每一種對應影片中的一個畫面：

1. NEURAL SHELL：琥珀綠配色，中央紅黃綠點陣球體＋旋轉線框立方體，兩側標籤框以曲線連到球體；上方機器人狀態大數字、K 線與掛單簿、市場生命週期條、紅綠到期格；下方綠紅訂單流、Gamma 扇形牆、Hawkes 橘色尖峰。
2. GLOBAL MESH：深藍底，點陣大陸地球自轉、城市間弧線與脈衝、場館卡片、成交串流、曝險甜甜圈、FX 矩陣、延遲直方圖、路由日誌、時段甘特圖。
3. SIGMA CORE：深青底，青色粒子殼內有黃色龍捲漩渦，左側輸入迷你圖、右側成交卡、執行明細、結算錐、邊際散點圖。
4. SURFACE GRID：紫底螢光綠，3D 波動曲面（紫→白→綠）在線框盒內緩慢擺動，探針提示框、期權鏈、四個希臘值儀表、微笑曲線、期限結構、風險熱圖、避險梯。
5. LIQUIDITY CORE：青色螺旋星系狀流動性漩渦（差速旋轉），兩側指標欄，下方訂單流頻譜瀑布持續往下捲動。
6. DEPTH BOOK：橘黃 3D 深度城市（左黃買單、右橘賣單，白色價格線穿過中間峽谷），流動性熱圖、逐筆成交、tick-to-trade 直方圖、注意力熱圖。
7. POLICY NET：洋紅／青色七層策略網路，脈衝沿連線流動，輸出 LONG／SHORT／FLAT 機率框，左側訓練損失、epoch、注意力、混淆矩陣等。
8. CHAOS ENGINE：同 1 的版型，中央換成綠→紅漸層的 Lorenz 混沌吸引子與線框盒。
9. EVO PROTOCOL：後段紅色介面，世代環形計數、世代線束、策略分群散點圖、開關設定、權益曲線與倖存策略清單。

面板與品牌名稱是虛構的，數字都是隨機示範資料，不含金額符號與錢包位址，頁面不會連網。橫幅固定寫：「UI 設計參考，非交易工具，數字為隨機示範」。可用上方按鈕、鍵盤 1–9 或網址 `#1`–`#9` 切換面板。開啟 `index.html` 即可（不需伺服器）。
